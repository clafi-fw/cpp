The manuals

These are the manuals of ClaFi, the Clarity First framework. The Quick Start produces a first application from four selections. Each of the others covers one subsystem from the caller's side: its purpose, the code a caller writes, and the rules that apply. They are listed in reading order, and each can be read on its own.

ManualCovers
Quick StartBuild a first application in any folder: select the platform, the toolchain and the form, and get the source files, build files and run command
PlatformThe platform object and its process-wide resources
LayoutMeasurement, alignment, sizing and spacing
ColorInks, pigments, grades, themes and color modes
GraphicsDrawing through the CPU and Direct2D backends
PathArtScene themes and weather effects
EventsEvent types, handlers, connections and dispatch
Selection and FocusFocus, the current item, selection and input routing
ActionsNamed commands and the controls that present them
GridColumns, rows, spans, groups and cell content

Text in ControlsHow a control stores, measures and draws its text
DomThe configuration tree, transactions, schemas and serializers

FAQCommon questions with their cause and fix
