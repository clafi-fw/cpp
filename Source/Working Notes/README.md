# Working Notes

These notes accompany the footnotes in the separate ClaFi SeeDocs project. Each subsystem's
working note and footnote share a name. The footnote explains what a framework user needs to
know. The working note explains why a subsystem works as it does and what happened on the way -
the alternatives weighed, the private members and the order things run in, the defects and what
they showed, the measurements, the things to watch. SeeDocs never reads these.

A heading here is the heading of the footnote it belongs with, so a section is found by the
declaration's name in both files, and a comment's `See <stem>` names the footnote. A subsystem
whose footnotes carry nothing of the author's has no note here.
